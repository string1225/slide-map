# 验证记录

2026-09-30，Windows / Node.js 24.13.0。

## 自动化

`npm run check`：共享校验、HTTP API、SQLite、微信接口模拟、页面生命周期测试与小程序构建。用例覆盖：

- 游客读权限、登录同意、私有列表鉴权、AppID 身份隔离、会话哈希存储和注销/过期。
- 防止伪造发布者、他人修改/删除、自评；重复与并发更新评分只保留一条评价，平均分随更新/删除变化。
- 收藏幂等、独立账号视图、举报去重、下架不可见和删除级联。
- 附近距离、跨国际日期线、字面搜索、类型/收费过滤、分页和非法参数。
- 内容检查失败不落库、上游错误不泄露凭据、文件数据库重启后可读。
- 地图请求乱序、取消定位后继续浏览、发布失败保留草稿、页面及权限声明完整性。

使用本机微信开发者工具自带 `wcc.exe`、`wcsc.exe` 对全部 WXML、WXSS 进行编译验证。产物位于被忽略的 artifacts 目录。

## 实际连通性

使用本机环境文件中的 AppID/Secret 请求微信 access_token：成功。日志仅记录成功状态，不输出 access_token、Secret 或带凭据的 URL。此项仅验证凭据有效性，不代替 code2Session 的真实用户登录、位置能力或内容安全权限验证。

## 浏览器交互

本机独立演示站点完成类型筛选、详情打开、演示账号登录、评价保存及均分更新、收藏、发布新地点和本人编辑入口验证。演示数据均明确标为虚构，不写入真实小程序数据库。检查桌面和手机宽度的排版及控制台错误。
